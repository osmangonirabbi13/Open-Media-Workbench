# ADR-0009: Background Jobs and Cancellation Protocol

**Status:** PROPOSED  
**Date:** 2026-10-13  
**Authors:** OpenTake Core Architecture Team  
**Deciders:** Lead Systems Architect, Systems Lead  
**Target Release:** v0.1.0 Beta  

---

## 1. Context & Problem Statement
Video probing, audio waveform extraction, silence analysis, and video export are long-running asynchronous tasks. If the user clicks "Cancel" or closes the window, child processes must be terminated cleanly and partial files removed, without leaving runaway orphan processes.

## 2. Decision Drivers
- Non-blocking UI: 60 FPS frontend responsiveness during heavy processing.
- Instant, safe cancellation ($\le 1{,}500\text{ ms}$).
- Process tree termination (killing child process and any grandchildren spawned).
- Guaranteed cleanup of registered temporary `.tmp` files.

## 3. Options Considered
- **Option 1 (Tokio Async Runtime with `CancellationToken` and Process Group PGID Killing):** Managed `ActiveJob` registry in Rust; `killpg` on Unix / Job Objects on Windows; automatic unlinking of registered temporary artifacts.
- **Option 2 (Single PID Kill via `child.kill()`):** Standard `std::process::Child::kill()` without process group management.
- **Option 3 (Blocking Threads without Cancellation):** Running tasks to completion without cancellation support.

## 4. Proposed Decision
Adopt **Option 1 (Tokio Async Runtime with `CancellationToken` and Process Group PGID Killing)**.

## 5. Consequences & Tradeoffs
- **Positive:** Complete immunity against orphan processes. Rapid return to ready state upon cancellation. Clean filesystem hygiene.
- **Negative:** Requires platform-specific process group management in Rust (`libc::killpg` vs Windows Job Objects).
- **Tradeoff Accepted:** Encapsulated in `crates/opentake-core/src/process/child_guard.rs`.

## 6. Risk Assessment & Alternatives Rejected
- Option 2 was rejected because killing only the direct PID leaves encoder subprocesses orphaned.
- Option 3 was rejected as an unacceptable user experience violation.
